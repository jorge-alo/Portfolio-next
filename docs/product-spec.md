# Product Specification — Portfolio de Jorge Altamirano

**Estado:** En desarrollo  
**Producto:** Portfolio profesional  
**Propietario:** Jorge Altamirano  
**Objetivo:** Posicionamiento profesional y generación de oportunidades laborales y freelance

---

# 1. Visión del producto

El producto es un portfolio web profesional destinado a presentar a Jorge Altamirano como **Fullstack Web Developer**.

El portfolio busca demostrar, mediante proyectos reales y funcionales, la capacidad de construir aplicaciones web completas, desde la interfaz de usuario hasta el backend y la base de datos.

El sitio tiene dos objetivos principales:

1. **Objetivo laboral:** generar oportunidades para incorporarse a equipos de desarrollo como Fullstack Developer.

2. **Objetivo freelance:** generar oportunidades para desarrollar aplicaciones web y soluciones digitales para clientes y negocios.

El portfolio no está orientado exclusivamente a presentar conocimientos o tecnologías, sino a **demostrar capacidades mediante productos construidos y problemas reales resueltos**.

---

# 2. Objetivos

## 2.1 Objetivo principal

Posicionar a Jorge Altamirano como un desarrollador Fullstack capaz de construir aplicaciones web completas y preparado para incorporarse a un equipo de desarrollo o participar en proyectos freelance.

## 2.2 Objetivos secundarios

- Mostrar experiencia práctica obtenida mediante proyectos propios.
- Demostrar conocimientos de frontend y backend.
- Mostrar capacidad para trabajar con bases de datos y APIs.
- Presentar proyectos SaaS completos.
- Permitir que los visitantes prueben las partes públicas de los productos.
- Facilitar el acceso al código fuente cuando corresponda.
- Facilitar el contacto profesional.
- Presentar formación y trayectoria de forma clara y profesional.
- Comunicar una actitud de aprendizaje continuo.
- Evitar depender exclusivamente de listas de tecnologías para demostrar conocimientos.

---

# 3. Público objetivo

El portfolio tiene dos públicos principales.

## 3.1 Reclutadores y empresas

Personas que buscan incorporar desarrolladores frontend o fullstack.

Sus principales necesidades son:

- entender rápidamente el perfil profesional;
- conocer las tecnologías utilizadas;
- evaluar la capacidad práctica;
- revisar proyectos reales;
- acceder al código;
- conocer la formación;
- contactar al candidato.

El portfolio debe permitir que un reclutador pueda comprender el perfil general en pocos segundos y profundizar posteriormente en los proyectos.

## 3.2 Clientes freelance

Personas, emprendedores, pequeños negocios y empresas que necesiten desarrollar una solución web.

Sus principales necesidades son:

- comprobar que el desarrollador puede construir productos reales;
- conocer ejemplos concretos;
- entender qué tipo de problemas puede resolver;
- probar productos existentes;
- contactar fácilmente para consultar un proyecto.

El portfolio no utilizará explícitamente la palabra "Junior" como parte de la identidad principal del sitio.

La condición de perfil Junior podrá comunicarse específicamente en el CV, LinkedIn o postulaciones laborales cuando sea necesario.

# 10. Proyecto destacado: AgendaOK

## 10.1 Descripción

AgendaOK es un SaaS destinado a automatizar la gestión de turnos y reservas para negocios de servicios personales como barberías, peluquerías y estéticas.

El sistema permite a los clientes reservar turnos online y a los negocios gestionar su agenda desde un panel administrativo.

## 10.2 Caso de estudio

AgendaOK dispone actualmente de un caso de estudio propio dentro del portfolio.

Ruta:

`/proyectos/agendaok`

El caso de estudio utiliza MDX y componentes React reutilizables.

La presentación incluye información sobre:

- visión general;
- problema;
- solución;
- funcionalidades;
- tecnologías;
- desafíos técnicos;
- arquitectura;
- enlaces relevantes.

## 10.3 Experiencia pública

El portfolio proporciona acceso a la experiencia pública de AgendaOK.

Actualmente se dispone de:

- Landing Page;
- Agenda pública/demo.

El visitante puede experimentar el flujo público de reserva.

## 10.4 Tecnologías

Las tecnologías principales utilizadas en el proyecto incluyen:

- React
- Vite
- CSS
- Node.js
- Express
- MySQL

El proyecto también utiliza infraestructura y servicios externos propios de su implementación.

## 10.5 Repositorio

El portfolio proporciona acceso al repositorio correspondiente.

# 25. Principios del producto

Durante el desarrollo se respetarán los siguientes principios.

### Mostrar antes que afirmar

Es preferible demostrar una capacidad mediante un proyecto que simplemente afirmar que se posee.

### Claridad antes que cantidad

El portfolio priorizará pocos proyectos bien presentados antes que una gran cantidad de proyectos secundarios.

### Honestidad profesional

No se deberá exagerar experiencia, seniority o conocimientos.

### Productos reales como principal evidencia

AgendaOK y Morfis serán los principales elementos de demostración.

### Experiencia práctica

El visitante deberá poder probar las partes públicas de los productos cuando sea posible.

### Profesionalismo

El sitio deberá sentirse como una presentación profesional y no como una colección de ejercicios de aprendizaje.

### Aprendizaje continuo

El portfolio podrá comunicar que Jorge continúa profundizando sus conocimientos.

# 29. Resumen

El portfolio será una plataforma profesional cuyo objetivo no es simplemente mostrar que Jorge conoce determinadas tecnologías, sino **demostrar mediante productos reales que puede construir aplicaciones web completas**.

Los dos proyectos principales serán:

- **AgendaOK**, SaaS de gestión de turnos.
- **Morfis**, SaaS de menú digital.

Ambos cuentan con casos de estudio, acceso a sus landing pages y acceso a sus experiencias públicas.

Los proyectos pequeños realizados durante el aprendizaje se mostrarán como contenido secundario.

El posicionamiento principal será:

> **Fullstack Web Developer**

El portfolio estará orientado simultáneamente a:

- oportunidades laborales;
- proyectos freelance.

La prioridad del producto será demostrar capacidad práctica, comunicar profesionalismo y facilitar el contacto.
